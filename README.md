# 🧠 NeuroTriage AI

An AI-powered emergency neurology triage platform designed to assist emergency departments in identifying, prioritizing, and managing patients with acute neurological conditions.

---

## Project Overview

NeuroTriage AI aims to reduce time-to-treatment for neurological emergencies by leveraging Artificial Intelligence for triage support, clinical prioritization, and workflow optimization.

This repository contains all project deliverables developed as part of the AI Product Management course.
